# AIGP training resources list v2.4.3

Further-reading list from the training course: about 180 links (laws, OECD/NIST/ISO material, reports, articles), grouped by module and lesson. Original: [PDF](../../_library/originals/AIGP_Resources_v2.4.3.pdf). Not for reproduction.

How to use it: when a lesson raises something worth going deeper on, open the linked item and clip it with the Web Clipper into `_agents/inbox/`; an agent then makes a source card and notes from it. Public sources (laws, OECD, NIST, UNESCO) are the best candidates.
